# Developer Certificate of Origin

RepoLens MCP uses a Developer Certificate of Origin style sign-off for contributions.

By adding a `Signed-off-by` line to a commit or pull request, you certify that you wrote the contribution, have the right to submit it under this project's license, or have permission to contribute it on behalf of its copyright holder.

Use the standard Git sign-off flag when committing:

```bash
git commit -s
```

The sign-off line should use your real name and an email address you are comfortable associating with the contribution:

```text
Signed-off-by: Your Name <you@example.com>
```

Maintainers may ask contributors to add or correct sign-offs before merging substantial code, workflow, release, or documentation changes.
